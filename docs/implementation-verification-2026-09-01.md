## 验证边界与人工待办

1. **证据可信度**：尚未运行外部模型或私有项目，也没有独立复核材料。模型效果、用户采用、跨任务迁移和社区影响仍需具体材料；完整缺项及复核流程见 `rubric-maintenance.md`。
2. **剪贴板**：当前自动化浏览器显示“已复制”，但剪贴板读回为空，且本地显式拒绝写入的 Permissions-Policy 未改变其模拟结果。因此不把这当作真实系统剪贴板成功或权限失败 UI 的完整验证，需用普通浏览器复核。
3. **真实键盘/辅助技术**：已检查原生按钮、焦点样式、对话框名称和 Escape 后焦点返回。自动化通道的 Enter/Space/Tab 没有稳定触发浏览器默认行为，尚未完成真实键盘循环、触屏硬件或屏幕阅读器审计；不能宣称全面 WCAG 合规。减少动画规则已实现并检查源码，但未通过 OS 设置切换验证。
4. **外部服务与托管**：未抓取外部链接，也未进行真实评论/分析服务调用测试；配置缺失时评论不加载。纯静态托管的安全响应头由托管层配置，newsletter POST 不属于静态站点能力。本轮未改变部署目标或发布网站。
