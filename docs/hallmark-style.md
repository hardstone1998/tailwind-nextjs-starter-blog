# Hallmark 风格选择：Console

本站推荐使用 Hallmark v2 的 **Console** 主题。主题源文件位于 [`.agents/skills/hallmark/references/themes/console.md`](../.agents/skills/hallmark/references/themes/console.md)，[示例图](../.agents/skills/hallmark/references/themes/console.jpg)展示的是深色版本。

## 选择依据

本站是多模态与视频系统工程师的双语作品集和研究笔记。读者主要查看项目、实验过程、评估证据和长篇技术文章。Console 的视觉语言来自实验记录：克制的底色、清晰的分隔线、用于测量值的等宽字，以及区分“人的判断”和“系统记录”的两种信号色。这些规则能承载本站已有的实验室、能力评估、项目案例与文章内容。

Hallmark 本次给出的另外两个候选为 Blueprint 和 Coral。Blueprint 的工程制图语言更贴近建筑图纸，通篇蓝底和大写标题会压过中文长文。Coral 的纸张与桌面质感适合产品流程，但与本站的研究和证据内容关联较弱。

## 应用方向

- **明暗模式**：浅色模式采用 Console 的 `paper` 色系，与现有浅色阅读体验衔接；深色模式采用 `graphite`。保留用户当前的明暗模式选择。
- **颜色含义**：蓝色表示系统、模型与测量；琥珀色表示作者判断、当前操作和需要关注的人工记录。成功与错误色只用于真实状态。
- **排版**：中文正文继续使用可靠的中文系统字体；等宽字体只用于指标、版本、时间戳和代码。标题保持简洁，长文优先保证行长、行距和层级。
- **版面**：首页突出一个真实项目或实验记录；项目页强调问题、做法、证据与局限；文章页保持阅读宽度。相邻信息可用细线分隔，避免堆叠卡片。
- **内容真实性**：只展示仓库中已有的项目、截图和数据，不补造指标、引用或客户标志。

这份选型已应用到全局配色、首页、项目与笔记列表及共用组件。可执行的设计规则见根目录的 [`design.md`](../design.md)；后续页面以该文件和 `css/tokens.css` 为准。
